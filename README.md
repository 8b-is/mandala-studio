# Omni × The Cheet — Family Mandala Studio

A single-file, dependency-free mandala studio for the whole family: click petals to
fill them, drag to draw mirrored kaleidoscope strokes across 6–24-fold symmetry,
toggle crisp line-art for physical coloring, and export print-ready **PNG** / **SVG**.
Includes a true multi-ring **ASCII mandala** generator (upgrading The Cheet's
original `o888o`) and a drop-in embed widget.

Live: <https://mandala.vaked.dev>

## Features
- **Family Mandala Studio** — click-to-fill petals, freehand kaleidoscope drawing, line-art toggle, PNG + SVG export.
- **Pure ASCII Mandala** — symmetric multi-ring ASCII art, custom glyphs, copy.
- **The Cheet + Put Him On Your Site** — copy-paste `<iframe>` embed.

## Run locally
Open `index.html` in any browser. No build, no network, no deps.

## Deploy
